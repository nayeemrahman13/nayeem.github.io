# nayeem.github.io

Personal site/portfolio. Vite + React 19, no backend, no secrets, no test framework.

## Commands

- Install: `npm install`
- Dev server: `npm run dev`
- Build: `npm run build`
- Lint: `npm run lint`

There is no test runner configured. Don't invent one or add a `test` script speculatively —
if a page grows real interactive logic that warrants tests, raise it first.

## Conventions

- Keep this a static, content-focused site. A component that needs client state beyond
  `useState`/`useReducer` is a signal to reconsider the approach, not to add a state library.
- Run `npm run lint` before calling a change done — it's the only automated check that exists.

## Boundaries

**Ask first**
- Adding any dependency beyond React itself and its Vite/ESLint tooling.
- Adding a backend, API route, or third-party data fetch.

**Never**
- Commit build output (`dist/`) — it's generated by `npm run build` and gitignored.

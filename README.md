# Nayeem Rahman

An interactive Instax-camera portfolio at [nayeem.nyc](https://nayeem.nyc), built with React and Vite.

## Development

- `npm run dev` starts the development server.
- `npm run lint` checks the code with ESLint.
- `npm run build` builds the site into the committed `docs/` directory.

Commit regenerated `docs/` output with site changes. The GitHub Pages workflow in `.github/workflows/deploy.yml` builds and deploys `docs/` on pushes to `master`.
